Установите Parallax_CubeMap_2.0.0.zip в Blender 4.5 или новее через Edit → Preferences → Add-ons → Install from Disk, предварительно отключив старый PX CubeMap Windows.
Выберите окно с готовой UV-развёрткой в пределах 0–1 и откройте N → Parallax.
«Назначить материал» покажет комнату, а «Debug-текстура» переключит её на проверочную текстуру.
«Вернуть материалы» восстановит прежние назначения и уберёт свободный слот Debug_Parallax; резерв сохраняется в blend-файле, так что вернуться можно и позже.
В Edit Mode кнопки работают с выделенными гранями и завершают действие в Object Mode — нажмите Tab, чтобы продолжить редактирование.
