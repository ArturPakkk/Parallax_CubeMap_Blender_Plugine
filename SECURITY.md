# Безопасность

Поддерживается актуальная версия Parallax_CubeMap 2.x.
Старый PX CubeMap Windows 1.3.1 сохраняется только как контекст миграции.

Для обычной ошибки используйте [Issues](https://github.com/ArturPakkk/Parallax_CubeMap_Blender_Plugine/issues).
Если проблема позволяет выполнять чужой код, читать посторонние файлы или терять
данные, используйте [приватное сообщение об уязвимости](https://github.com/ArturPakkk/Parallax_CubeMap_Blender_Plugine/security/advisories/new),
если эта функция доступна, либо контакты в [профиле автора](https://github.com/ArturPakkk).
Не публикуйте пароли, токены и чужие проекты.

В сообщении нужны версия аддона и Blender, ОС, шаги воспроизведения, последствия
и минимальный пример без личных данных. Срок ответа заранее не гарантируется.

Код аддона не обращается к сети, не запускает внешние программы и не меняет
глобальные Preferences или горячие клавиши. Пакет содержит только Python-код,
две EXR и короткие документы. Подробности проверок: [AUDIT.md](docs/AUDIT.md).
Python-расширения Blender не являются изолированной песочницей.
