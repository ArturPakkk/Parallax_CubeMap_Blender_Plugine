# Участие в разработке

Спасибо за помощь с Parallax_CubeMap.

Для ошибки укажите версию Blender, ОС, режим Object/Edit и последовательность
нажатий. Для проблем с UV приложите скриншот и минимальный пример, который
можно свободно передавать; удалите из него личные и чужие платные ресурсы.

Перед pull request:

1. Обсудите крупное изменение в issue; небольшое исправление можно прислать сразу.
2. Проверьте поведение в Blender 4.5 и более новой поддерживаемой версии.
3. Запустите проверки из [DEVELOPMENT.md](docs/DEVELOPMENT.md).
4. Для изменения назначения проверьте частичное выделение, общий Mesh,
   Ctrl+Z/Redo и возврат материалов после сохранения файла.

Сохраняйте существующие UV и пользовательские материалы. Не добавляйте скрытые
обработчики, сеть, запись настроек Blender или внешние зависимости в код аддона.
Новые подписи и сообщения должны иметь английский и русский варианты.
Изменения ресурсов сопровождайте источником, лицензией и обновлёнными хешами.

Новые исходники и ресурсы принимаются под GPL-3.0-or-later, если отдельно не
согласовано иное. Авторство сохраняется за авторами; отправляйте только то,
на что у вас есть права.
